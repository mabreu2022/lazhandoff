# Exemplo Prático: Módulo 26 - TDlpRealtimeChartEngine (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpRealtimeChartEngine`** desenvolvido no **Módulo 26** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Gráfico de séries temporais com buffer circular para plotagem de até 100.000 pontos a 60 FPS.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_26_DlpRealtimeChartEngine.dproj`.
3. Pressione **F9** para compilar e executar.
