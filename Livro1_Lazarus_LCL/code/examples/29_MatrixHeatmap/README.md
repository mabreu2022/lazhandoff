# Exemplo Prático: Módulo 29 - TLazMatrixHeatmap

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazMatrixHeatmap`** desenvolvido no **Módulo 29** do livro.

## 🧭 O que este componente faz:
Visualizador de densidade e intensidade térmica com interpolação de cores contínua.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_29_LazMatrixHeatmap.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_29_LazMatrixHeatmap.lpi
```
