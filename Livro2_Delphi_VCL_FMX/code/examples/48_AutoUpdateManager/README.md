# Exemplo Prático: Módulo 48 - TDlpAutoUpdateManager (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpAutoUpdateManager`** desenvolvido no **Módulo 48** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Verifica novas versões remotas, baixa binários, valida SHA-256 e reinicia com atualização.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_48_DlpAutoUpdateManager.dproj`.
3. Pressione **F9** para compilar e executar.
