# Exemplo Prático: Módulo 36 - TDlpSecurityRoleManager (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpSecurityRoleManager`** desenvolvido no **Módulo 36** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Varre os controles do formulário e ajusta visibilidade/habilitação conforme privilégios de usuário.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_36_DlpSecurityRoleManager.dproj`.
3. Pressione **F9** para compilar e executar.
