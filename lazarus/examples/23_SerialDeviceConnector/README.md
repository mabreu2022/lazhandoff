# Exemplo Prático: Módulo 23 - TLazSerialDeviceConnector

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazSerialDeviceConnector`** desenvolvido no **Módulo 23** do livro.

## 🧭 O que este componente faz:
Comunicação com balanças, leitores e CLPs industriais via RS232 e USB Virtual COM.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_23_LazSerialDeviceConnector.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_23_LazSerialDeviceConnector.lpi
```
