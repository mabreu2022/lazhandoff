# Exemplo Prático: Módulo 42 - TDlpAiPromptDispatcher (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpAiPromptDispatcher`** desenvolvido no **Módulo 42** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Integração com servidores locais de IA (Ollama) ou APIs cloud com streaming de tokens.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_42_DlpAiPromptDispatcher.dproj`.
3. Pressione **F9** para compilar e executar.
