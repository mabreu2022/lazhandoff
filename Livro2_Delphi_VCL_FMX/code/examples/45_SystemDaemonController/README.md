# Exemplo Prático: Módulo 45 - TDlpSystemDaemonController (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpSystemDaemonController`** desenvolvido no **Módulo 45** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Controle e criação de serviços em background (Windows Services e Linux Daemons Systemd).

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_45_DlpSystemDaemonController.dproj`.
3. Pressione **F9** para compilar e executar.
