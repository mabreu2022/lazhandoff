# Exemplo Prático: Módulo 08 - TLazCleanArchFormWizard

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazCleanArchFormWizard`** desenvolvido no **Módulo 08** do livro.

## 🧭 O que este componente faz:
Wizard que cria esqueletos de projetos e formulários baseados em Clean Architecture.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_08_LazCleanArchFormWizard.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_08_LazCleanArchFormWizard.lpi
```
