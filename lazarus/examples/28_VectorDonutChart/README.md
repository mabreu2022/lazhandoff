# Exemplo Prático: Módulo 28 - TLazVectorDonutChart

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazVectorDonutChart`** desenvolvido no **Módulo 28** do livro.

## 🧭 O que este componente faz:
Gráfico de rosca com cálculo polar de fatias, detecção de clique na fatia e destaque visual.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_28_LazVectorDonutChart.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_28_LazVectorDonutChart.lpi
```
