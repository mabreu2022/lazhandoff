# Exemplo Prático: Módulo 01 - TDlpTypeHierarchyInspector (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpTypeHierarchyInspector`** desenvolvido no **Módulo 01** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Inspeciona em tempo de execução a árvore de herança e propriedades published via RTTI.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_01_DlpTypeHierarchyInspector.dproj`.
3. Pressione **F9** para compilar e executar.
