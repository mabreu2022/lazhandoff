# Exemplo Prático: Módulo 03 - TDlpEncryptedDataStore (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpEncryptedDataStore`** desenvolvido no **Módulo 03** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Serializa e comprime buffers binários diretamente no streaming do formulário via DefineProperties.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_03_DlpEncryptedDataStore.dproj`.
3. Pressione **F9** para compilar e executar.
