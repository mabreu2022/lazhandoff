# Exemplo Prático: Módulo 24 - LazComponentTests

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`LazComponentTests`** desenvolvido no **Módulo 24** do livro.

## 🧭 O que este componente faz:
Valida ciclo de vida, ausência de memory leaks e estresse de componentes sob Heaptrc/FastMM5.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_24_LazComponentTests.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_24_LazComponentTests.lpi
```
