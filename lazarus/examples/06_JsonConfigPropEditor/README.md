# Exemplo Prático: Módulo 06 - TLazJsonConfig

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazJsonConfig`** desenvolvido no **Módulo 06** do livro.

## 🧭 O que este componente faz:
Exibe como o Object Inspector pode ser estendido com janelas modais ([...]) e listas dinâmicas.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_06_LazJsonConfig.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_06_LazJsonConfig.lpi
```
