# Exemplo Prático: Módulo 20 - TLazProductStockIndicator

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazProductStockIndicator`** desenvolvido no **Módulo 20** do livro.

## 🧭 O que este componente faz:
Badge gráfico de nível de estoque atual, reposição e cálculo percentual de margens comerciais.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_20_LazProductStockIndicator.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_20_LazProductStockIndicator.lpi
```
