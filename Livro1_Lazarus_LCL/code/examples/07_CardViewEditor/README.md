# Exemplo Prático: Módulo 07 - TLazCardView

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazCardView`** desenvolvido no **Módulo 07** do livro.

## 🧭 O que este componente faz:
Componente com verbos de menu de contexto no clique direito do Form Designer da IDE.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_07_LazCardView.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_07_LazCardView.lpi
```
