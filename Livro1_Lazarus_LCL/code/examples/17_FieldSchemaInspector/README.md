# Exemplo Prático: Módulo 17 - TLazFieldSchemaInspector

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazFieldSchemaInspector`** desenvolvido no **Módulo 17** do livro.

## 🧭 O que este componente faz:
Lê metadados de colunas do DataSet e suporta drag-and-drop de campos para a tela.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_17_LazFieldSchemaInspector.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_17_LazFieldSchemaInspector.lpi
```
