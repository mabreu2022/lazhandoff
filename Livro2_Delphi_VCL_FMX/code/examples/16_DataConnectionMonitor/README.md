# Exemplo Prático: Módulo 16 - TDlpDataConnectionMonitor (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpDataConnectionMonitor`** desenvolvido no **Módulo 16** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Audita tempo de execução de queries SQL em milissegundos e alerta para consultas lentas.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_16_DlpDataConnectionMonitor.dproj`.
3. Pressione **F9** para compilar e executar.
