# Exemplo Prático: Módulo 49 - TLazCodeBenchmarkHarness

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazCodeBenchmarkHarness`** desenvolvido no **Módulo 49** do livro.

## 🧭 O que este componente faz:
Mede tempo de execução de blocos de código com resolução de nanossegundos via RDTSC / QPC.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_49_LazCodeBenchmarkHarness.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_49_LazCodeBenchmarkHarness.lpi
```
