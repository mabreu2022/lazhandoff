# Exemplo Prático: Módulo 41 - TDlpPushNotificationHub (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpPushNotificationHub`** desenvolvido no **Módulo 41** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Despacha notificações em nuvem para smartphones e navegadores com formatação de mensagens.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_41_DlpPushNotificationHub.dproj`.
3. Pressione **F9** para compilar e executar.
