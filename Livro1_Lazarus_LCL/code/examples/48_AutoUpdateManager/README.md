# Exemplo Prático: Módulo 48 - TLazAutoUpdateManager

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazAutoUpdateManager`** desenvolvido no **Módulo 48** do livro.

## 🧭 O que este componente faz:
Verifica novas versões remotas, baixa binários, valida SHA-256 e reinicia com atualização.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_48_LazAutoUpdateManager.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_48_LazAutoUpdateManager.lpi
```
