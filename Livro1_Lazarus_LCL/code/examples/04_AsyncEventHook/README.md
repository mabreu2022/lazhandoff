# Exemplo Prático: Módulo 04 - LazAsyncEventHook

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`LazAsyncEventHook`** desenvolvido no **Módulo 04** do livro.

## 🧭 O que este componente faz:
Intercepta mensagens de janela do SO em baixo nível e dispara eventos desacoplados.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_04_LazAsyncEventHook.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_04_LazAsyncEventHook.lpi
```
