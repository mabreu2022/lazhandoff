# Exemplo Prático: Módulo 11 - TDlpCustomTabBar (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpCustomTabBar`** desenvolvido no **Módulo 11** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Barra de abas moderna baseada em TCollection com badges de notificação e botões de fechamento.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_11_DlpCustomTabBar.dproj`.
3. Pressione **F9** para compilar e executar.
