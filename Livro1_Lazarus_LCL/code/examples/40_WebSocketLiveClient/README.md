# Exemplo Prático: Módulo 40 - TLazWebSocketLiveClient

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazWebSocketLiveClient`** desenvolvido no **Módulo 40** do livro.

## 🧭 O que este componente faz:
Comunicação full-duplex bidirecional contínua com ping/pong periódico e reconexão automática.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_40_LazWebSocketLiveClient.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_40_LazWebSocketLiveClient.lpi
```
