# Exemplo Prático: Módulo 44 - TDlpVectorEmbeddingStore (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpVectorEmbeddingStore`** desenvolvido no **Módulo 44** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Armazenamento em memória de vetores com cálculo de Similaridade por Cosseno para RAG.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_44_DlpVectorEmbeddingStore.dproj`.
3. Pressione **F9** para compilar e executar.
