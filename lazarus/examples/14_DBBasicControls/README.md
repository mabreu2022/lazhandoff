# Exemplo Prático: Módulo 14 - TLazDBBasicControls

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazDBBasicControls`** desenvolvido no **Módulo 14** do livro.

## 🧭 O que este componente faz:
Labels, Edits e CheckBoxes DB-Aware sincronizados atomicamente com buffer de dados.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_14_LazDBBasicControls.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_14_LazDBBasicControls.lpi
```
