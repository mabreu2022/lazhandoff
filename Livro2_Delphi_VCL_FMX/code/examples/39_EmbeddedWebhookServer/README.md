# Exemplo Prático: Módulo 39 - TDlpEmbeddedWebhookServer (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpEmbeddedWebhookServer`** desenvolvido no **Módulo 39** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Microservidor HTTP que escuta portas TCP para recebimento de webhooks externos em tempo real.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_39_DlpEmbeddedWebhookServer.dproj`.
3. Pressione **F9** para compilar e executar.
