# Exemplo Prático: Módulo 24 - DlpComponentTests (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`DlpComponentTests`** desenvolvido no **Módulo 24** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Valida ciclo de vida, ausência de memory leaks e estresse de componentes sob Heaptrc/FastMM5.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_24_DlpComponentTests.dproj`.
3. Pressione **F9** para compilar e executar.
