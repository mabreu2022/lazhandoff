# Exemplo Prático: Módulo 03 - TLazBinaryBlobContainer

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazBinaryBlobContainer`** desenvolvido no **Módulo 03** do livro.

## 🧭 O que este componente faz:
Serializa e comprime buffers binários diretamente no streaming do formulário via DefineProperties.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_03_LazBinaryBlobContainer.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_03_LazBinaryBlobContainer.lpi
```
