# Exemplo Prático: Módulo 46 - TLazSystemMetricsProbe

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazSystemMetricsProbe`** desenvolvido no **Módulo 46** do livro.

## 🧭 O que este componente faz:
Mede em tempo de execução percentual de CPU, memória RAM alocada, threads e handles de SO.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_46_LazSystemMetricsProbe.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_46_LazSystemMetricsProbe.lpi
```
