# Exemplo Prático: Módulo 04 - TDlpWindowsMessageInterceptor (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpWindowsMessageInterceptor`** desenvolvido no **Módulo 04** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Intercepta mensagens de janela do SO em baixo nível e dispara eventos desacoplados.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_04_DlpWindowsMessageInterceptor.dproj`.
3. Pressione **F9** para compilar e executar.
