# Exemplo Prático: Módulo 19 - TDlpCRUDOperationsBar (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpCRUDOperationsBar`** desenvolvido no **Módulo 19** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Barra de botões (Novo, Editar, Gravar, Excluir, Cancelar) com controle automático de estados.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_19_DlpCRUDOperationsBar.dproj`.
3. Pressione **F9** para compilar e executar.
