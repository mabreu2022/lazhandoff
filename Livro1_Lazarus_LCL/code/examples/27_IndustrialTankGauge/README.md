# Exemplo Prático: Módulo 27 - TLazIndustrialTankGauge

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazIndustrialTankGauge`** desenvolvido no **Módulo 27** do livro.

## 🧭 O que este componente faz:
Mostrador visual de reservatórios com gradientes térmicos, efeito de ondas e alarmes de nível.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_27_LazIndustrialTankGauge.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_27_LazIndustrialTankGauge.lpi
```
