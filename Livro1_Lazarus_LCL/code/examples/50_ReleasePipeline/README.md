# Exemplo Prático: Módulo 50 - LazReleasePipeline

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`LazReleasePipeline`** desenvolvido no **Módulo 50** do livro.

## 🧭 O que este componente faz:
Automação de compilação em lote via linha de comando, empacotamento e releases no GitHub.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_50_LazReleasePipeline.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_50_LazReleasePipeline.lpi
```
