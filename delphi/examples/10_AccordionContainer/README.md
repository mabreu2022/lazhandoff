# Exemplo Prático: Módulo 10 - TDlpAccordionContainer (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpAccordionContainer`** desenvolvido no **Módulo 10** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Painel colapsável com controles filhos embutidos (csAcceptsControls) e animação suave.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_10_DlpAccordionContainer.dproj`.
3. Pressione **F9** para compilar e executar.
