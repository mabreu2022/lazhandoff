# Exemplo Prático: Módulo 47 - TDlpDatabaseConnectionPool (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpDatabaseConnectionPool`** desenvolvido no **Módulo 47** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Pooling thread-safe de conexões com banco de dados para sistemas de alto tráfego concorrente.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_47_DlpDatabaseConnectionPool.dproj`.
3. Pressione **F9** para compilar e executar.
