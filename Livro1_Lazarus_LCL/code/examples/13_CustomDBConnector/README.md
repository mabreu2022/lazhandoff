# Exemplo Prático: Módulo 13 - TLazCustomDBConnector

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazCustomDBConnector`** desenvolvido no **Módulo 13** do livro.

## 🧭 O que este componente faz:
Ponte arquitetural com TDataLink para sincronizar controles visuais com DataSets.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_13_LazCustomDBConnector.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_13_LazCustomDBConnector.lpi
```
