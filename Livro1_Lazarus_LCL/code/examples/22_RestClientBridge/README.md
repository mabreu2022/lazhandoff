# Exemplo Prático: Módulo 22 - TLazRestClientBridge

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazRestClientBridge`** desenvolvido no **Módulo 22** do livro.

## 🧭 O que este componente faz:
Cliente HTTP de alta velocidade para chamadas REST (GET, POST, PUT, DELETE) com Bearer Token.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_22_LazRestClientBridge.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_22_LazRestClientBridge.lpi
```
