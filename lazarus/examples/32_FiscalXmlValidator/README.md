# Exemplo Prático: Módulo 32 - TLazFiscalXmlValidator

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazFiscalXmlValidator`** desenvolvido no **Módulo 32** do livro.

## 🧭 O que este componente faz:
Valida chave de acesso de NF-e (44 dígitos com Módulo 11) e integridade de digest SHA-1.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_32_LazFiscalXmlValidator.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_32_LazFiscalXmlValidator.lpi
```
