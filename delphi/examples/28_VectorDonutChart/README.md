# Exemplo Prático: Módulo 28 - TDlpVectorDonutChart (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpVectorDonutChart`** desenvolvido no **Módulo 28** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Gráfico de rosca com cálculo polar de fatias, detecção de clique na fatia e destaque visual.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_28_DlpVectorDonutChart.dproj`.
3. Pressione **F9** para compilar e executar.
