# Exemplo Prático: Módulo 21 - TLazAsyncTaskRunner

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazAsyncTaskRunner`** desenvolvido no **Módulo 21** do livro.

## 🧭 O que este componente faz:
Processa operações pesadas em segundo plano sem congelar a interface gráfica com cancelamento seguro.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_21_LazAsyncTaskRunner.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_21_LazAsyncTaskRunner.lpi
```
