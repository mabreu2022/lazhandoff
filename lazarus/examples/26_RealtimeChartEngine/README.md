# Exemplo Prático: Módulo 26 - TLazRealtimeChartEngine

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazRealtimeChartEngine`** desenvolvido no **Módulo 26** do livro.

## 🧭 O que este componente faz:
Gráfico de séries temporais com buffer circular para plotagem de até 100.000 pontos a 60 FPS.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_26_LazRealtimeChartEngine.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_26_LazRealtimeChartEngine.lpi
```
