# Exemplo Prático: Módulo 06 - TDlpGradientHeader (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpGradientHeader`** desenvolvido no **Módulo 06** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Exibe como o Object Inspector pode ser estendido com janelas modais ([...]) e listas dinâmicas.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_06_DlpGradientHeader.dproj`.
3. Pressione **F9** para compilar e executar.
