# Exemplo Prático: Módulo 20 - TDlpProductStockIndicator (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpProductStockIndicator`** desenvolvido no **Módulo 20** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Badge gráfico de nível de estoque atual, reposição e cálculo percentual de margens comerciais.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_20_DlpProductStockIndicator.dproj`.
3. Pressione **F9** para compilar e executar.
