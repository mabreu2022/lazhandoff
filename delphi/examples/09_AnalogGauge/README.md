# Exemplo Prático: Módulo 09 - TDlpAnalogGauge (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpAnalogGauge`** desenvolvido no **Módulo 09** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Instrumento visual leve de alta performance (60 FPS com Double Buffering) com agulha e zonas de alerta.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_09_DlpAnalogGauge.dproj`.
3. Pressione **F9** para compilar e executar.
