# Exemplo Prático: Módulo 08 - TDlpCleanArchProjectWizard (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpCleanArchProjectWizard`** desenvolvido no **Módulo 08** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Wizard que cria esqueletos de projetos e formulários baseados em Clean Architecture.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_08_DlpCleanArchProjectWizard.dproj`.
3. Pressione **F9** para compilar e executar.
