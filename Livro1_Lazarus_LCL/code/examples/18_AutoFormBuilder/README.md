# Exemplo Prático: Módulo 18 - TLazAutoFormBuilder

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazAutoFormBuilder`** desenvolvido no **Módulo 18** do livro.

## 🧭 O que este componente faz:
Constrói formulários de cadastro completos e alinhados automaticamente a partir de RTTI.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_18_LazAutoFormBuilder.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_18_LazAutoFormBuilder.lpi
```
