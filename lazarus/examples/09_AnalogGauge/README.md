# Exemplo Prático: Módulo 09 - TLazAnalogGauge

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazAnalogGauge`** desenvolvido no **Módulo 09** do livro.

## 🧭 O que este componente faz:
Instrumento visual leve de alta performance (60 FPS com Double Buffering) com agulha e zonas de alerta.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_09_LazAnalogGauge.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_09_LazAnalogGauge.lpi
```
