# Exemplo Prático: Módulo 33 - TLazEncryptedZipArchive

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazEncryptedZipArchive`** desenvolvido no **Módulo 33** do livro.

## 🧭 O que este componente faz:
Compactação e extração de ZIPs protegidos por senha via algoritmo padrão PKWARE com CRC-32.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_33_LazEncryptedZipArchive.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_33_LazEncryptedZipArchive.lpi
```
