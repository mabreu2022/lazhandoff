# Exemplo Prático: Módulo 47 - TLazDatabaseConnectionPool

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazDatabaseConnectionPool`** desenvolvido no **Módulo 47** do livro.

## 🧭 O que este componente faz:
Pooling thread-safe de conexões com banco de dados para sistemas de alto tráfego concorrente.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_47_LazDatabaseConnectionPool.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_47_LazDatabaseConnectionPool.lpi
```
