# Exemplo Prático: Módulo 35 - TDlpCryptoVaultStorage (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpCryptoVaultStorage`** desenvolvido no **Módulo 35** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Armazenamento em memória blindado com ofuscação XOR contra dumps não autorizados de RAM.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_35_DlpCryptoVaultStorage.dproj`.
3. Pressione **F9** para compilar e executar.
