# Exemplo Prático: Módulo 15 - TLazDBLookupTagBox

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazDBLookupTagBox`** desenvolvido no **Módulo 15** do livro.

## 🧭 O que este componente faz:
Entrada de dados com chips/tags selecionáveis a partir de uma tabela de lookup relacional.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_15_LazDBLookupTagBox.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_15_LazDBLookupTagBox.lpi
```
