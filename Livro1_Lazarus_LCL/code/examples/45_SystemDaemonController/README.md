# Exemplo Prático: Módulo 45 - TLazSystemDaemonController

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazSystemDaemonController`** desenvolvido no **Módulo 45** do livro.

## 🧭 O que este componente faz:
Controle e criação de serviços em background (Windows Services e Linux Daemons Systemd).

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_45_LazSystemDaemonController.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_45_LazSystemDaemonController.lpi
```
