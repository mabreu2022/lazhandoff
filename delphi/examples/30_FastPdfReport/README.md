# Exemplo Prático: Módulo 30 - TDlpFastPdfReport (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpFastPdfReport`** desenvolvido no **Módulo 30** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Criação de arquivos PDF em código Pascal puro sem depender de impressoras ou DLLs externas.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_30_DlpFastPdfReport.dproj`.
3. Pressione **F9** para compilar e executar.
