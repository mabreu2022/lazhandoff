# Exemplo Prático: Módulo 16 - TLazDataConnectionMonitor

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazDataConnectionMonitor`** desenvolvido no **Módulo 16** do livro.

## 🧭 O que este componente faz:
Audita tempo de execução de queries SQL em milissegundos e alerta para consultas lentas.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_16_LazDataConnectionMonitor.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_16_LazDataConnectionMonitor.lpi
```
