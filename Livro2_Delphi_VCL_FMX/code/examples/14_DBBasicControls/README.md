# Exemplo Prático: Módulo 14 - TDlpDBBasicControls (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpDBBasicControls`** desenvolvido no **Módulo 14** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Labels, Edits e CheckBoxes DB-Aware sincronizados atomicamente com buffer de dados.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_14_DlpDBBasicControls.dproj`.
3. Pressione **F9** para compilar e executar.
