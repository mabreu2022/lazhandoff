# Exemplo Prático: Módulo 07 - TDlpDashboardCard (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpDashboardCard`** desenvolvido no **Módulo 07** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Componente com verbos de menu de contexto no clique direito do Form Designer da IDE.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_07_DlpDashboardCard.dproj`.
3. Pressione **F9** para compilar e executar.
