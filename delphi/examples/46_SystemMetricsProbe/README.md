# Exemplo Prático: Módulo 46 - TDlpSystemMetricsProbe (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpSystemMetricsProbe`** desenvolvido no **Módulo 46** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Mede em tempo de execução percentual de CPU, memória RAM alocada, threads e handles de SO.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_46_DlpSystemMetricsProbe.dproj`.
3. Pressione **F9** para compilar e executar.
