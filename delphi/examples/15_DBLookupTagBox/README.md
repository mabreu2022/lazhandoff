# Exemplo Prático: Módulo 15 - TDlpDBLookupTagBox (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpDBLookupTagBox`** desenvolvido no **Módulo 15** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Entrada de dados com chips/tags selecionáveis a partir de uma tabela de lookup relacional.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_15_DlpDBLookupTagBox.dproj`.
3. Pressione **F9** para compilar e executar.
