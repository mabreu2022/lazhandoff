# Exemplo Prático: Módulo 32 - TDlpFiscalXmlValidator (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpFiscalXmlValidator`** desenvolvido no **Módulo 32** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Valida chave de acesso de NF-e (44 dígitos com Módulo 11) e integridade de digest SHA-1.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_32_DlpFiscalXmlValidator.dproj`.
3. Pressione **F9** para compilar e executar.
