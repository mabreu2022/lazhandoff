# Exemplo Prático: Módulo 10 - TLazAccordionContainer

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazAccordionContainer`** desenvolvido no **Módulo 10** do livro.

## 🧭 O que este componente faz:
Painel colapsável com controles filhos embutidos (csAcceptsControls) e animação suave.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_10_LazAccordionContainer.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_10_LazAccordionContainer.lpi
```
