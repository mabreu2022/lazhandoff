# Exemplo Prático: Módulo 31 - TLazDataExportPipeline

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazDataExportPipeline`** desenvolvido no **Módulo 31** do livro.

## 🧭 O que este componente faz:
Exporta grandes volumes de registros para CSV, JSON Lines e XML Spreadsheet em background.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_31_LazDataExportPipeline.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_31_LazDataExportPipeline.lpi
```
