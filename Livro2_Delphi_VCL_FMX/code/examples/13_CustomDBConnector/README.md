# Exemplo Prático: Módulo 13 - TDlpCustomDBConnector (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpCustomDBConnector`** desenvolvido no **Módulo 13** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Ponte arquitetural com TDataLink para sincronizar controles visuais com DataSets.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_13_DlpCustomDBConnector.dproj`.
3. Pressione **F9** para compilar e executar.
