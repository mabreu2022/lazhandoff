# Exemplo Prático: Módulo 30 - TLazFastPdfReport

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazFastPdfReport`** desenvolvido no **Módulo 30** do livro.

## 🧭 O que este componente faz:
Criação de arquivos PDF em código Pascal puro sem depender de impressoras ou DLLs externas.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_30_LazFastPdfReport.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_30_LazFastPdfReport.lpi
```
