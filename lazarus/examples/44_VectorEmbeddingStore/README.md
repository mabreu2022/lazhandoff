# Exemplo Prático: Módulo 44 - TLazVectorEmbeddingStore

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazVectorEmbeddingStore`** desenvolvido no **Módulo 44** do livro.

## 🧭 O que este componente faz:
Armazenamento em memória de vetores com cálculo de Similaridade por Cosseno para RAG.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_44_LazVectorEmbeddingStore.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_44_LazVectorEmbeddingStore.lpi
```
