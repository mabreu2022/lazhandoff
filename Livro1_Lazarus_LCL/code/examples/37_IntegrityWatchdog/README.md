# Exemplo Prático: Módulo 37 - TLazIntegrityWatchdog

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazIntegrityWatchdog`** desenvolvido no **Módulo 37** do livro.

## 🧭 O que este componente faz:
Calcula o hash SHA-256 do binário para detectar alterações maliciosas e injeções de código.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_37_LazIntegrityWatchdog.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_37_LazIntegrityWatchdog.lpi
```
