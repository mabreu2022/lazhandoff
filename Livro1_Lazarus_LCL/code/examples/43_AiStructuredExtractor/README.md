# Exemplo Prático: Módulo 43 - TLazAiStructuredExtractor

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazAiStructuredExtractor`** desenvolvido no **Módulo 43** do livro.

## 🧭 O que este componente faz:
Higieniza texto livre de IA, extrai blocos JSON limpos e hidrata registros Pascal tipados.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_43_LazAiStructuredExtractor.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_43_LazAiStructuredExtractor.lpi
```
