# Exemplo Prático: Módulo 29 - TDlpMatrixHeatmap (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpMatrixHeatmap`** desenvolvido no **Módulo 29** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Visualizador de densidade e intensidade térmica com interpolação de cores contínua.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_29_DlpMatrixHeatmap.dproj`.
3. Pressione **F9** para compilar e executar.
