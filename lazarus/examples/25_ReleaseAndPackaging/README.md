# Exemplo Prático: Módulo 25 - LazPackageRegister

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`LazPackageRegister`** desenvolvido no **Módulo 25** do livro.

## 🧭 O que este componente faz:
Empacotamento semântico de pacotes para o repositório oficial da comunidade.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_25_LazPackageRegister.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_25_LazPackageRegister.lpi
```
