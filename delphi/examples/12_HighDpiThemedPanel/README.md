# Exemplo Prático: Módulo 12 - TDlpHighDpiThemedPanel (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpHighDpiThemedPanel`** desenvolvido no **Módulo 12** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Painel com bordas arredondadas e sombras suaves com escalonamento dinâmico em telas 4K.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_12_DlpHighDpiThemedPanel.dproj`.
3. Pressione **F9** para compilar e executar.
