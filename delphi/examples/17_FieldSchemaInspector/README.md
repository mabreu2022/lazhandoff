# Exemplo Prático: Módulo 17 - TDlpFieldSchemaInspector (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpFieldSchemaInspector`** desenvolvido no **Módulo 17** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Lê metadados de colunas do DataSet e suporta drag-and-drop de campos para a tela.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_17_DlpFieldSchemaInspector.dproj`.
3. Pressione **F9** para compilar e executar.
