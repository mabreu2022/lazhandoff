# Exemplo Prático: Módulo 49 - TDlpCodeBenchmarkHarness (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpCodeBenchmarkHarness`** desenvolvido no **Módulo 49** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Mede tempo de execução de blocos de código com resolução de nanossegundos via RDTSC / QPC.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_49_DlpCodeBenchmarkHarness.dproj`.
3. Pressione **F9** para compilar e executar.
