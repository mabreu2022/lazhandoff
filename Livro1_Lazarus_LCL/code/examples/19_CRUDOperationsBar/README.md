# Exemplo Prático: Módulo 19 - TLazCRUDOperationsBar

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazCRUDOperationsBar`** desenvolvido no **Módulo 19** do livro.

## 🧭 O que este componente faz:
Barra de botões (Novo, Editar, Gravar, Excluir, Cancelar) com controle automático de estados.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_19_LazCRUDOperationsBar.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_19_LazCRUDOperationsBar.lpi
```
