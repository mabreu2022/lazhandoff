# Exemplo Prático: Módulo 05 - LazPackageRegister

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`LazPackageRegister`** desenvolvido no **Módulo 05** do livro.

## 🧭 O que este componente faz:
Centraliza o registro oficial na Tool Palette com separação Runtime vs Design-time.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_05_LazPackageRegister.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_05_LazPackageRegister.lpi
```
