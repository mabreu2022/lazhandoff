# Exemplo Prático: Módulo 40 - TDlpWebSocketLiveClient (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpWebSocketLiveClient`** desenvolvido no **Módulo 40** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Comunicação full-duplex bidirecional contínua com ping/pong periódico e reconexão automática.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_40_DlpWebSocketLiveClient.dproj`.
3. Pressione **F9** para compilar e executar.
