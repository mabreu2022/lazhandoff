# Exemplo Prático: Módulo 34 - TLazJwtSecurityManager

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazJwtSecurityManager`** desenvolvido no **Módulo 34** do livro.

## 🧭 O que este componente faz:
Geração e validação de tokens JWT (RFC 7519) com HMAC-SHA256 e lista de revogação.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_34_LazJwtSecurityManager.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_34_LazJwtSecurityManager.lpi
```
