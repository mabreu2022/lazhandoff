# Exemplo Prático: Módulo 39 - TLazEmbeddedWebhookServer

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazEmbeddedWebhookServer`** desenvolvido no **Módulo 39** do livro.

## 🧭 O que este componente faz:
Microservidor HTTP que escuta portas TCP para recebimento de webhooks externos em tempo real.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_39_LazEmbeddedWebhookServer.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_39_LazEmbeddedWebhookServer.lpi
```
