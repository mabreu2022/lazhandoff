# Exemplo Prático: Módulo 21 - TDlpAsyncTaskRunner (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpAsyncTaskRunner`** desenvolvido no **Módulo 21** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Processa operações pesadas em segundo plano sem congelar a interface gráfica com cancelamento seguro.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_21_DlpAsyncTaskRunner.dproj`.
3. Pressione **F9** para compilar e executar.
