# Exemplo Prático: Módulo 02 - TLazSafeLinkedPanel

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazSafeLinkedPanel`** desenvolvido no **Módulo 02** do livro.

## 🧭 O que este componente faz:
Painel com gerenciamento de referências fracas e FreeNotification para evitar dangling pointers.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_02_LazSafeLinkedPanel.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_02_LazSafeLinkedPanel.lpi
```
