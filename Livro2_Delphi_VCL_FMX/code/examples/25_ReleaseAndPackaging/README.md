# Exemplo Prático: Módulo 25 - DlpPackageRegister (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`DlpPackageRegister`** desenvolvido no **Módulo 25** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Empacotamento semântico de pacotes para o repositório oficial da comunidade.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_25_DlpPackageRegister.dproj`.
3. Pressione **F9** para compilar e executar.
