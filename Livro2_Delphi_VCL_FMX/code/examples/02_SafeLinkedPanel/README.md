# Exemplo Prático: Módulo 02 - TDlpSafeLinkedContainer (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpSafeLinkedContainer`** desenvolvido no **Módulo 02** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Painel com gerenciamento de referências fracas e FreeNotification para evitar dangling pointers.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_02_DlpSafeLinkedContainer.dproj`.
3. Pressione **F9** para compilar e executar.
