# Exemplo Prático: Módulo 36 - TLazSecurityRoleManager

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazSecurityRoleManager`** desenvolvido no **Módulo 36** do livro.

## 🧭 O que este componente faz:
Varre os controles do formulário e ajusta visibilidade/habilitação conforme privilégios de usuário.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_36_LazSecurityRoleManager.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_36_LazSecurityRoleManager.lpi
```
