# Exemplo Prático: Módulo 01 - TLazTypeInfoInspector

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazTypeInfoInspector`** desenvolvido no **Módulo 01** do livro.

## 🧭 O que este componente faz:
Inspeciona em tempo de execução a árvore de herança e propriedades published via RTTI.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_01_LazTypeInfoInspector.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_01_LazTypeInfoInspector.lpi
```
