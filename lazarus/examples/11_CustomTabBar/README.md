# Exemplo Prático: Módulo 11 - TLazCustomTabBar

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazCustomTabBar`** desenvolvido no **Módulo 11** do livro.

## 🧭 O que este componente faz:
Barra de abas moderna baseada em TCollection com badges de notificação e botões de fechamento.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_11_LazCustomTabBar.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_11_LazCustomTabBar.lpi
```
