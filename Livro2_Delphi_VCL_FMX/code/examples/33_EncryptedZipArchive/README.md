# Exemplo Prático: Módulo 33 - TDlpEncryptedZipArchive (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpEncryptedZipArchive`** desenvolvido no **Módulo 33** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Compactação e extração de ZIPs protegidos por senha via algoritmo padrão PKWARE com CRC-32.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_33_DlpEncryptedZipArchive.dproj`.
3. Pressione **F9** para compilar e executar.
