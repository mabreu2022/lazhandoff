# Exemplo Prático: Módulo 37 - TDlpIntegrityWatchdog (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpIntegrityWatchdog`** desenvolvido no **Módulo 37** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Calcula o hash SHA-256 do binário para detectar alterações maliciosas e injeções de código.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_37_DlpIntegrityWatchdog.dproj`.
3. Pressione **F9** para compilar e executar.
