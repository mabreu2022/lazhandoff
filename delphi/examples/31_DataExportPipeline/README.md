# Exemplo Prático: Módulo 31 - TDlpDataExportPipeline (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpDataExportPipeline`** desenvolvido no **Módulo 31** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Exporta grandes volumes de registros para CSV, JSON Lines e XML Spreadsheet em background.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_31_DlpDataExportPipeline.dproj`.
3. Pressione **F9** para compilar e executar.
