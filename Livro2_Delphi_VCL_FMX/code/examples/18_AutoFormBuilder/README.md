# Exemplo Prático: Módulo 18 - TDlpAutoFormBuilder (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpAutoFormBuilder`** desenvolvido no **Módulo 18** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Constrói formulários de cadastro completos e alinhados automaticamente a partir de RTTI.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_18_DlpAutoFormBuilder.dproj`.
3. Pressione **F9** para compilar e executar.
