# Exemplo Prático: Módulo 43 - TDlpAiStructuredExtractor (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpAiStructuredExtractor`** desenvolvido no **Módulo 43** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Higieniza texto livre de IA, extrai blocos JSON limpos e hidrata registros Pascal tipados.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_43_DlpAiStructuredExtractor.dproj`.
3. Pressione **F9** para compilar e executar.
