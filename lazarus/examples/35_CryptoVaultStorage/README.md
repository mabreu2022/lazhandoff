# Exemplo Prático: Módulo 35 - TLazCryptoVaultStorage

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazCryptoVaultStorage`** desenvolvido no **Módulo 35** do livro.

## 🧭 O que este componente faz:
Armazenamento em memória blindado com ofuscação XOR contra dumps não autorizados de RAM.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_35_LazCryptoVaultStorage.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_35_LazCryptoVaultStorage.lpi
```
