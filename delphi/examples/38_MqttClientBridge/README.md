# Exemplo Prático: Módulo 38 - TDlpMqttClientBridge (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpMqttClientBridge`** desenvolvido no **Módulo 38** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Comunicação com brokers MQTT (QoS 0, 1 e 2) para telemetria de sensores industriais e IoT.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_38_DlpMqttClientBridge.dproj`.
3. Pressione **F9** para compilar e executar.
