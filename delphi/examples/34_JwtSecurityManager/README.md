# Exemplo Prático: Módulo 34 - TDlpJwtSecurityManager (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpJwtSecurityManager`** desenvolvido no **Módulo 34** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Geração e validação de tokens JWT (RFC 7519) com HMAC-SHA256 e lista de revogação.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_34_DlpJwtSecurityManager.dproj`.
3. Pressione **F9** para compilar e executar.
