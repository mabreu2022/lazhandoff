# Exemplo Prático: Módulo 27 - TDlpIndustrialTankGauge (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpIndustrialTankGauge`** desenvolvido no **Módulo 27** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Mostrador visual de reservatórios com gradientes térmicos, efeito de ondas e alarmes de nível.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_27_DlpIndustrialTankGauge.dproj`.
3. Pressione **F9** para compilar e executar.
