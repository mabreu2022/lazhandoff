# Exemplo Prático: Módulo 50 - DlpReleasePipeline (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`DlpReleasePipeline`** desenvolvido no **Módulo 50** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Automação de compilação em lote via linha de comando, empacotamento e releases no GitHub.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_50_DlpReleasePipeline.dproj`.
3. Pressione **F9** para compilar e executar.
