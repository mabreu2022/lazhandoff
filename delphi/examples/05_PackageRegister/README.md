# Exemplo Prático: Módulo 05 - DlpPackageRegister (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`DlpPackageRegister`** desenvolvido no **Módulo 05** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Centraliza o registro oficial na Tool Palette com separação Runtime vs Design-time.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_05_DlpPackageRegister.dproj`.
3. Pressione **F9** para compilar e executar.
