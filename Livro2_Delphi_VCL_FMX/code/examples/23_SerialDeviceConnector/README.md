# Exemplo Prático: Módulo 23 - TDlpSerialDeviceConnector (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpSerialDeviceConnector`** desenvolvido no **Módulo 23** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Comunicação com balanças, leitores e CLPs industriais via RS232 e USB Virtual COM.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_23_DlpSerialDeviceConnector.dproj`.
3. Pressione **F9** para compilar e executar.
