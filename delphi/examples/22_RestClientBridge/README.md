# Exemplo Prático: Módulo 22 - TDlpRestClientBridge (Delphi)

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TDlpRestClientBridge`** desenvolvido no **Módulo 22** do livro para Delphi 12 Athens+.

## 🧭 O que este componente faz:
Cliente HTTP de alta velocidade para chamadas REST (GET, POST, PUT, DELETE) com Bearer Token.

## 🚀 Como Executar este Exemplo no Delphi:
1. Abra o Embarcadero Delphi 12 Athens+.
2. Acesse **File -> Open Project...** e selecione o arquivo `Demo_22_DlpRestClientBridge.dproj`.
3. Pressione **F9** para compilar e executar.
