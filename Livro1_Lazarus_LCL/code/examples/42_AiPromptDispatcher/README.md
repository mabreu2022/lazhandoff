# Exemplo Prático: Módulo 42 - TLazAiPromptDispatcher

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazAiPromptDispatcher`** desenvolvido no **Módulo 42** do livro.

## 🧭 O que este componente faz:
Integração com servidores locais de IA (Ollama) ou APIs cloud com streaming de tokens.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_42_LazAiPromptDispatcher.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_42_LazAiPromptDispatcher.lpi
```
