# Exemplo Prático: Módulo 38 - TLazMqttClientBridge

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazMqttClientBridge`** desenvolvido no **Módulo 38** do livro.

## 🧭 O que este componente faz:
Comunicação com brokers MQTT (QoS 0, 1 e 2) para telemetria de sensores industriais e IoT.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_38_LazMqttClientBridge.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_38_LazMqttClientBridge.lpi
```
