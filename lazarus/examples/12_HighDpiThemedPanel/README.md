# Exemplo Prático: Módulo 12 - TLazHighDpiThemedPanel

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazHighDpiThemedPanel`** desenvolvido no **Módulo 12** do livro.

## 🧭 O que este componente faz:
Painel com bordas arredondadas e sombras suaves com escalonamento dinâmico em telas 4K.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_12_LazHighDpiThemedPanel.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_12_LazHighDpiThemedPanel.lpi
```
