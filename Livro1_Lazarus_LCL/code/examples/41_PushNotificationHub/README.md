# Exemplo Prático: Módulo 41 - TLazPushNotificationHub

Este projeto demonstra de forma isolada e limpa como utilizar o componente **`TLazPushNotificationHub`** desenvolvido no **Módulo 41** do livro.

## 🧭 O que este componente faz:
Despacha notificações em nuvem para smartphones e navegadores com formatação de mensagens.

## 🚀 Como Executar este Exemplo no Lazarus:
1. Abra o Lazarus IDE.
2. Acesse **Projeto -> Abrir Projeto...** e selecione o arquivo `Demo_41_LazPushNotificationHub.lpi`.
3. Pressione **F9** para compilar e executar.

## 💻 Como Compilar via Linha de Comando:
```bash
lazbuild Demo_41_LazPushNotificationHub.lpi
```
